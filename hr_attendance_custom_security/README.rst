=============================
Hr Attendance Custom Security
=============================

* This module adds read permissions for the field ``attendance_manager_id`` 
  in the *Employee (hr.employee)* model for users belonging to a specific group.
* It allows users in the group to access the **“Attendances / Overview”** menu.
